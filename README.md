# E.L.B.E.R.R
E.L.B.B.E.R - Epistemic Logic-Based Engine for Recursive Reasoning. A self aware robot, brought to you through an AI website, soon to be a robot.


Setup of README.md in the files:

Windows

Install Python 3 from:
https://www.python.org/downloads/

Open Command Prompt.

Go to the E.L.B.E.R.R. folder:

cd "C:\path\to\E.L.B.E.R.R"

Create the virtual environment:

python -m venv .venv

Activate it:

.venv\Scripts\activate

Install the required packages:

pip install -r requirements.txt

Start E.L.B.E.R.R.:

python -m uvicorn server:app --host 127.0.0.1 --port 8000

Open this in your browser:

http://127.0.0.1:8000

To start E.L.B.E.R.R. again later:

cd "C:\path\to\E.L.B.E.R.R"
.venv\Scripts\activate
python -m uvicorn server:app --host 127.0.0.1 --port 8000

Stopping E.L.B.E.R.R.:

Press CTRL + C

iPhone and iPad

The current version is intended to run the E.L.B.E.R.R. backend on a computer or server.

You can access the E.L.B.E.R.R. website from Safari while the E.L.B.E.R.R. server is running on another computer or server.

Stopping E.L.B.E.R.R.:

On the computer or server running E.L.B.E.R.R., press CTRL + C
